# Tone & Retouch — bản cập nhật

Kho này chỉ chứa **file phát hành** của Tone & Retouch (SAY Media): bản cập nhật tự động và bộ cài.
Không có mã nguồn.

## Cài lần đầu hoặc cài lại — Windows

1. Mở **Releases** → bản mới nhất.
2. Tải `Tai-bo-cai-Tone-Retouch.bat` vào một thư mục còn trống ít nhất 8 GB, rồi bấm đúp vào nó.
   File này sẽ:
   - tự tải bộ cài (khoảng 3,8 GB; mất mạng thì chạy lại, nó tải tiếp từ chỗ đã có);
   - kiểm tra file;
   - mở bộ cài.

   Muốn tải tay: tải mọi file `Tone-Retouch-Setup-…-win.exe.001`, `.002`, … vào cùng một thư mục, mở Command Prompt
   ở đó rồi ghép:

       copy /b Tone-Retouch-Setup-<bản>-win.exe.001 + Tone-Retouch-Setup-<bản>-win.exe.002 + … Tone-Retouch-Setup.exe

## Cài lần đầu hoặc cài lại — Mac chip Apple (M1 / M2 / M3 / M4)

1. Mở **Releases** → bản mới nhất, tải `Tone-Retouch-Setup-<bản>-mac-arm64.dmg` (khoảng 1,2 GB), bấm đúp để mở.
2. Kéo **cả** thư mục `Tone&Retouch` vào Applications (Ứng dụng).
3. Mở thư mục đó, **chuột phải** vào `Mở Tone&Retouch.command` › Mở (Open). Lần sau chỉ cần nhấp đúp.

Mac chip Intel: chưa có bản mới trên kênh này.

## Tự cập nhật

Từ bản **2026.10.23.2** trở đi, app tự báo khi có bản mới. Bản nào cần cài lại thì app tự tải bộ cài về, bạn bấm
**Cài ngay** là xong.

Thiết lập và dữ liệu của bạn giữ nguyên khi cài lại.
